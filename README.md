# 구강현 | 소프트웨어 개발자 이력서

GitHub Pages에 올릴 수 있는 정적 사이트 파일입니다. `index.html` 한 파일에 페이지 스타일과 필요한 이미지가 포함되어 있어 별도 빌드 없이 게시할 수 있습니다.

## GitHub Pages 배포

1. `github-pages-ready` 폴더의 파일(`index.html`, `.nojekyll`, `README.md`)을 GitHub 저장소 루트에 업로드합니다.
2. GitHub 저장소에서 **Settings → Pages**를 엽니다.
3. **Build and deployment**의 Source를 **Deploy from a branch**로 선택합니다.
4. 배포 브랜치를 `main`, 폴더를 `/ (root)`로 지정하고 저장합니다.
5. Pages 설정 화면에 표시되는 사이트 주소에서 배포 결과를 확인합니다.

페이지 내용이나 이미지를 바꿀 때는 `index.html`을 수정한 뒤 같은 저장소에 반영하면 됩니다.
